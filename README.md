# SpaceMan 3D — 3D Platformer Game (Unity)

## 🛰️ Overview
**SpaceMan 3D** is a 3D platformer developed in **Unity** inspired by classic precision-jumping games.  
Players control a space explorer navigating vertical obstacle courses, combining physics-based movement with stylized visuals.  
---

## 🎮 Features
- Physics-based movement and jumping mechanics  
- Layered background and environment design  
- Custom 3D models and textures integrated through Unity’s asset system  
- Camera control and collision detection logic built with C#  
- Shader and lighting tweaks using **ShaderLab** and **HLSL**

---

## 🧰 Tools & Technologies
- **Engine:** Unity  
- **Languages:** C#, ShaderLab, HLSL  
- **Version Control:** GitHub

## 🚀 Development Notes
- Implemented game logic using Unity’s physics engine and C# scripts.
